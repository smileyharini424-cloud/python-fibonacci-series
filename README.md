# Fibonacci Series Generator

## Explanation

The Fibonacci series is a sequence in which each number is the sum of the two preceding numbers.

## Problem Statement

Write a Python program to generate the first `n` terms of the Fibonacci series.

## Features

* Accepts number of terms
* Generates Fibonacci numbers
* Uses an iterative approach
* Handles invalid input

## How It Works

1. Start with 0 and 1.
2. Add the previous two numbers to generate the next number.
3. Repeat until the requested number of terms is generated.
4. Display the series.
